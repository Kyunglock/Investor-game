# 고양이 카드 초상화

`cat-portraits.png`는 `app/assets/icon-only.png`를 참고해 생성한 정면 초상화 아틀라스다. 4열 × 2행, 정사각형 칸을 `CatPortrait.tsx`에서 SVG viewBox로 표시한다.

- 윗줄: 사장냥(치즈 태비), 하늘냥(접힌 귀), 민트냥(장모), 라일락냥(윙크·흰 얼굴 무늬)
- 아랫줄: 노을냥(삼색·웃음), 밤냥(턱시도·호박색 눈), 눈꽃냥(흰 장모·파란 눈), 빈 칸

카드, 출전 슬롯, 무기 장착 표시, 단일/10연속 뽑기 결과에서 공유한다. 전투 스프라이트와 별도 자산이다. 캐릭터별 색상 필터를 겹치지 않는다.
