# 고양이 카드 초상화

`cat-portraits.png`는 `app/assets/icon-only.png`를 참고해 생성한 정면 초상화 아틀라스다. 4열 × 2행, 정사각형 칸을 `CatPortrait.tsx`에서 SVG viewBox로 표시한다.

- 윗줄: 사장냥(치즈 태비), 하늘냥(접힌 귀), 민트냥(장모), 라일락냥(윙크·흰 얼굴 무늬)
- 아랫줄: 노을냥(삼색·웃음), 밤냥(턱시도·호박색 눈), 눈꽃냥(흰 장모·파란 눈), 빈 칸

카드, 출전 슬롯, 무기 장착 표시, 단일/10연속 뽑기 결과에서 공유한다. 전투 스프라이트와 별도 자산이다. 캐릭터별 색상 필터를 겹치지 않는다.

## 하단 메뉴 아이콘 B안 (2026-11-15)

`menu-icons.png`는 사용자가 선택한 B안(선명한 캐주얼 스타일)을 바탕으로 생성한 투명 PNG다. 왼쪽부터 벽 돌파, 성장 화살표, 장난감 총, 고양이 얼굴, 가게다. `MenuIcon.tsx`의 SVG viewBox가 각 영역을 표시하며, 하단 메뉴에서만 사용한다. 글자는 이미지에 포함하지 않고 기존 버튼 레이블을 유지한다.

## 신규 동료 33종 (2026-11-15)

승인 시안 08~40의 초상화는 `../../mental/assets/roster/` 원본에 전투 자세와 함께 보관한다. `CatPortrait`가 `catRosterFrames.json`의 초상화 영역만 읽으며 기존 7종은 위 원본을 유지한다.

## 카드용 얼굴 아틀라스 (`cat-faces.webp`)

화면에서는 위 원본을 직접 받지 않는다. `scripts/catFaceAtlas.py`가 기존 7종(`cat-portraits.png`)과 신규 33종(roster 원본의 초상화 영역)의 얼굴만 잘라 256px 칸 8×5 WebP 한 장(약 0.6MB)과 위치표 `cat-face-rects.json`으로 만든다. 1~2MB짜리 전투 원본 11장(약 19MB)을 카드 하나 그리려고 받지 않게 하려는 것이다. 원본이나 `catRosterFrames.json`이 바뀌면 스크립트를 다시 돌린다. 이 아틀라스는 로딩 화면에서 가장 먼저 미리 받는다.
