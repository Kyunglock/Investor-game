# 로딩 화면 그림

`loading-squad.png`는 사용자가 선택한 B안(고양이 출동형)을 바탕으로 생성한 전용 그림이다. 앱 아이콘의 치즈 고양이, 회색·흰색 동료, 장난감 총, 파란 벽돌과 게임 제목을 포함한다.

진행률·상태·도움말은 그림에 넣지 않고 `LoadingScreen.tsx`에서 실제 상태로 표시한다. HTML 첫 화면과 React 화면이 같은 자산을 공유하며, 첫 HTML에서 미리 받는다. 전체 그림을 유지해서 작은 화면과 가로 화면에서도 얼굴과 제목이 잘리지 않게 한다.

게임 이름 변경에 따라 그림 속 로고도 **매도벽 돌파냥**으로 교체했다(2026-11-17). 기존 그림을 이미지 편집 도구에 제공하고, 고양이·배경·구도를 유지하며 위쪽은 크림색 `매도벽`, 아래쪽은 금색 `돌파냥`으로 요청했다.
