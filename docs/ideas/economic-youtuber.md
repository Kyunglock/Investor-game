# 아이디어: 경제 유튜버 (구현 예정 아님)

> 상태: 아이디어 메모 (사용자 요청, 지금 구현하지 않음). 세부는 모두 제안이다.

## 요지

- 사용자가 **경제 유튜버를 골라 구독**하고 도움(조언)을 받을 수 있다 (확정 방향).
- 하지만 유튜버를 **따라 샀다가 폭망하는 이야기**도 있어야 한다 (확정 방향). 웃음 포인트이자 억울함의 또 다른 원천.

## 제안 메커니즘

| 항목 | 제안 |
|---|---|
| 선택 시점 | 투자 시작 후 이벤트로 "구독할 유튜버" 선택지 등장. 언제든 갈아탈 수 있게 할지는 미정 |
| 유튜버 유형 | 신중한 분석가(적중률 보통, 손실 작음), 화끈한 단타왕(적중률 낮음, 변동 큼), 숨은 고수(적중률 높음, 드물게 등장), 어그로 사기꾼(초반 적중 후 폭망 유도) |
| 도움 방식 | 뉴스마다 유튜버 코멘트("지금 풀매수!")를 힌트 옆에 표시. 안목 힌트와 별개의 정보원 |
| 숨은 값 | 유튜버마다 서버에만 있는 적중률·편향. 클라이언트에는 내려보내지 않는다 |
| 줏대와 연결 | 줏대가 낮으면 유튜버 말을 따라가는 이탈이 추가로 생긴다(기존 "다른 뉴스" 판정과 같은 구조) |
| 폭망 스토리 | 연결 뉴스(갈래)로 "유튜버 추천주 → 급등 → 유튜버가 몰래 매도 → 폭락" 같은 이야기 묶음. 결과 화면에 "유튜버를 믿었다가…" 원인 표시 |
| 결과 집계 | 최종 결과에 "유튜버 따라 산 횟수 / 손익"을 보여 준다 |

## 영향받는 도메인 (구현 시)

- 콘텐츠: 유튜버 정의, 코멘트 문구, 폭망 이야기 묶음
- 이벤트 운영: 유튜버 선택 이벤트, 코멘트 생성, 이야기 연결
- 행동: 유튜버에 휘둘리는 이탈 판정 (줏대)
- 진행·결과: 구독 상태, 결과 요약

## 미결정

1. 유튜버 수와 유형, 유료 구독(월급 지출) 여부
2. 유튜버를 바꿀 수 있는지, 바꾸면 손해가 있는지
3. 뉴스 연결(갈래) 기능이 먼저 필요하다 (아직 미구현)
