고양이 증권사 시안

그림 규칙둥근 머리에 작은 몸, 점 눈, 작은 귀, 갈색 가는 윤곽, 파스텔 면
  • 픽셀 없음. 캔버스 경로(타원·둥근 다각형)로 그린다. 윤곽은 검정이 아니라 갈색(#4a3528) 2.5px, 면은 채도 낮은 파스텔. 그림자는 발밑 연한 타원 하나.
  • 한 덩어리 실루엣. 머리·몸·팔·발·귀를 따로 선으로 나누지 않고 바깥 윤곽선 하나만 두른다(부위를 잉크색으로 먼저 깔고 털색으로 덮는 방식). 눈은 작은 점, 입은 아주 작게, 볼은 연분홍.
  • 작게. 전투에서 플레이어는 화면 높이의 1/12쯤(레퍼런스 비율), 적은 그보다 조금 작다.
  • 품종·소품이 변수. 털 무늬(단색·줄무늬·턱시도·삼색·포인트), 소품(넥타이·나비넥타이·리본·안경·선글라스·목도리·왕관). 모두 같은 함수.
  • 총은 작게, 탄은 주황 줄기. 레퍼런스처럼 총은 손에 쏙 들어가는 회색 권총, 탄은 주황 빛줄기와 노란 불빛, 떨어지는 건 초록 지폐.

컨셉 고르기 (24)

같은 몸, 색·무늬·소품만 다르다. 번호로 골라 주면 그걸 플레이어로 올린다. 마음에 드는 걸 여러 개 골라 섞어도 된다.

크림 사장냥

"다른 모델로"를 누르면 아래 후보가 차례로 전투에 선다. 적(패닉셀·투기)도 같은 규칙으로 다시 그렸다.

플레이어 모델 후보

왼쪽이 가만히, 오른쪽이 총을 든 모습. 노란 칸이 추천.

적 넷

같은 윤곽 규칙으로 단순하게. 이름이 곧 생김새다.

표정

가만히 / 쏘기 / 맞음 / 특급 뽑힘 / 사표 / 잠. 점 눈이라 표정은 눈 모양과 입, 땀·별 같은 작은 기호로 낸다.

같은 규칙으로 직원들

품종이 개성이고 등급 차림새(후드티·셔츠·정장)는 소품으로 얹는다. 사무실·채용 카드·합성판에 그대로.

추천과 다음

플레이어는 1번 "크림 사장냥"(크림색 + 빨간 넥타이 + 선글라스)을 추천한다. 레퍼런스와 가장 가깝고, 넥타이와 선글라스만으로 "사장"이 읽히며, 맞으면 선글라스가 벗겨져 표정 변화가 크다. 선글라스가 부담스러우면 2번(맨 얼굴).
