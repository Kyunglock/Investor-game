# PoC: 투자자 시뮬레이터 핵심 루프

> 상태: 초안 · 대화에서 확정된 내용과 **(추측)** 으로 표시한 제안을 구분해 적었다.

## 1. PoC가 검증할 것

한 줄 질문: **"내가 고른 선택이 능력치 확률에 의해 뒤집히는 경험이 재미있는가?"**

| 검증 항목 | 성공 기준 |
|---|---|
| 억울함 | 선택이 뒤집혔을 때 원인(어떤 능력치 부족)이 한눈에 보인다 |
| 양방향성 | 뒤집힘이 손해만 주지 않고, 득이 되는 경우도 체감된다 |
| 동기 | 플레이 후 "능력치를 키워서 극복하고 싶다"는 마음이 든다 |
| 힌트 | 애매한 문구만으로도 "믿을지 말지" 고민하게 된다 |

## 2. 범위

**포함 (핵심 루프만)**

- 랜덤 캐릭터 생성 (능력치 5종, 초기 자산)
- 뉴스 이벤트 → 매수 / 매도 / 관망 선택
- 선택이 확률로 뒤집히는 판정
- 안목 기반 애매한 힌트 문구
- 결과 화면: "선택 → 실제 행동 + 원인" 표시
- 능력치 성장 (아래 6절, 추측)

**제외 (PRD 단계에서 다룸)**

- 직업 선택 이벤트, 월급, 저축 단계
- 투자 성향 형성 이벤트, 관심 섹터 정립
- "투자 시작" 전환 시점
- 실제 시세·실제 뉴스 연동, 영속 저장, 계정

## 3. 능력치 (확정)

| 능력치 | 역할 | 부족할 때 | 성장 |
|---|---|---|---|
| 안목 | 정보 품질 | 힌트가 모호하거나 틀림 | 가능 |
| 인내심 | 과잉 행동 | 관망 선택이 충동 매수·패닉 매도로 바뀜 | 가능 |
| 용기 | 행동 불발 | 매수·매도를 눌러도 실행 못 하고 관망 | 가능 |
| 줏대 | 외부 영향 | 다른 뉴스에 휘둘려 매수·매도가 정해짐 | 가능 |
| 운 | 결과 편차 | 손실이 더 크게 남 | **불가 (타고난 값)** |

- 능력치와 초기 자산은 게임 시작 시 랜덤.
- 후보: 탐욕(익절 못 하고 더 들고 감)은 핵심 루프 확인 후 추가.
- 능력치는 코드가 아닌 설정 데이터로 정의해 추가 비용을 낮춘다.

## 4. 한 라운드의 흐름

1. 뉴스 이벤트가 뜬다. 헤드라인은 중립적이고, 주가 방향(오름/내림)은 숨겨진 값이다.
2. 화면에는 헤드라인, 안목 힌트 문구, 그리고 **다른 뉴스 한 건**(줏대 판정용)이 같이 보인다.
3. 사용자가 매수 / 매도 / 관망을 고른다.
4. **줏대 판정**: 실패하면 다른 뉴스의 분위기(긍정이면 매수, 부정이면 매도)를 따른다.
5. 그 결과가 **관망이면 인내심 판정**, 매수·매도이면 **용기 판정**을 한다.
   - 인내심 실패: 충동 매수 (보유 중이면 일부 확률로 매도)
   - 용기 실패: 관망으로 바뀜
6. 주가가 움직이고 손익이 정해진다. 손실일 때만 **운 판정**으로 손실이 줄어들 수 있다.
7. 결과 화면에서 "선택 → 실제 행동", 원인, 손익, 정답을 보여 준다.

## 5. 판정 수식 (PoC 초기값, 추측)

능력치는 0~100 기준.

```
이탈 확률(줏대·인내심·용기) = (1 - 능력치/100) × 0.5      # 능력치 0이면 50%, 100이면 0%
힌트 정답률               = 0.25 + (안목/100) × 0.55       # 안목 0이면 25%, 100이면 80%
운 판정(손실일 때만)      = 확률 (운/100) × 0.3 으로 손실을 0.3배로 축소
매수 금액                 = 현금의 30%
주가 변동                 = ±3% ~ ±15%, 방향은 50:50
```

- 초기 능력치 범위는 15~85, 초기 자산은 100만~5,000만 원 (추측).
- 능력치가 100이어도 이탈이 0%가 되므로, 실제 제품에서는 상한(예: 95)을 둔다 (추측).

## 6. 안목 힌트 (확정 방향 + 문구는 추측)

- 확률 숫자는 보여 주지 않고 **애매한 문구**만 보여 준다.
- 안목이 높을수록 방향이 맞고 또렷하다. 낮으면 모호하거나 틀린 쪽으로 기운다.

| 상태 | 문구 예시 |
|---|---|
| 유리 (약) | "유리할지도?", "느낌이 나쁘진 않은데…" |
| 유리 (강, 안목 높을 때) | "꽤 유리해 보이는데?" |
| 불리 (약) | "불안한데…", "위험할지도?" |
| 불리 (강, 안목 높을 때) | "이건 위험해 보인다" |
| 모호 (안목 낮을 때) | "글쎄…", "잘 모르겠다" |

## 7. 능력치 성장 (미확정, 추측안)

- 이탈을 겪은 능력치는 경험치로 조금 오른다. 이탈 1회당 +2 정도.
- 확률은 줄어들 뿐 사라지지 않는다. 높은 사용자도 가끔 흔들린다.
- 월급을 쓰는 자기계발 이벤트로도 오를 수 있다. 이 부분은 PoC 범위 밖이다.

## 8. 화면 구성

| 화면 | 보여 줄 것 |
|---|---|
| 캐릭터 | 능력치 5종, 초기 자산 |
| 뉴스 | 헤드라인, 힌트 문구, 다른 뉴스, 보유 현황, 3개 버튼 |
| 결과 | 선택 → 실제 행동, 원인 문구, 주가 변동, 손익, 정답, 성장 알림 |
| 종료 | 시작 자산 대비 최종 자산, 능력치 변화 |

한 판은 10라운드 내외.

## 9. 수식 검증 결과

설계한 확률이 의도대로 나오는지 시뮬레이션으로 확인했다 (각 20,000회).

| 조건 | 결과 | 기대값 |
|---|---|---|
| 관망 선택 → 실제 행동 발생 (인내심 0) | 50.2% | 50% |
| 관망 선택 → 실제 행동 발생 (인내심 100) | 0.0% | 0% |
| 매수 선택 → 관망으로 바뀜 (용기 0) | 50.4% | 50% |
| 매수 선택 → 관망으로 바뀜 (용기 100) | 0.0% | 0% |
| 매수 선택 → 다른 행동으로 바뀜 (줏대 0) | 24.6% | 약 25% (※) |
| 힌트 정답률 (안목 10 / 50 / 90) | 15.3% / 51.8% / 74.5% | 약 31% / 52% / 74% (※) |

※ 줏대 0에서는 이탈 확률이 50%지만, 다른 뉴스가 긍정(매수)이면 선택과 같아서 뒤집힘이 아니다. 그래서 약 25%가 맞다.
※ 안목 10은 모호한 문구(neutral)가 최대 50% 나오고 이는 정답률에서 오답으로 센다. 그래서 기대값 31%보다 낮다.

결론: 이탈 판정 로직은 설계대로 동작한다. 수식 계수는 체감 테스트 후 조정한다.
