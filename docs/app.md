# 안드로이드 앱

> 상태: 토이시티 메인 적용 (2026-11-08, decisions.md 360번). 웹과 같은 서버·규칙을 쓰되, 폰 게임처럼 **한 화면씩 넘기는 앱 전용 화면**(`app/`)을 Capacitor WebView에 담은 안드로이드 앱이다.

## 1. 무엇인가

- `app/`이 앱 패키지다. `app/src/`가 앱 화면, `app/android/`가 안드로이드 프로젝트, `app/capacitor.config.ts`가 앱 이름(흔들리지 않는 고양이)·패키지(`com.kyunglock.investorgame`)·화면을 어디서 가져올지를 정한다.
- **토이시티 메인** (360번): 파란 지붕·크림색 건물과 고양이가 있는 거리다. 위에는 실제 자본·확장 진행률, 양옆에는 채용·인력 관리·이슈·기록·확장·멘탈, 아래에는 소식·분기 넘기기·팀 분위기가 있다. 메인에 책상·빈 자리·자리 선택 버튼을 그리지 않는다. 실제 배치된 직원만 고양이로 보이고, 채용과 배치는 별도 탭에서 한다. 서버 응답으로 등급이 바뀌면 좌우 라이벌을 번갈아 밀어내며 카메라가 물러나고 건물 전체가 튀어 오르듯 확장된다. 오를 때의 연출(399번, 2.4초)은 다섯 단계다: ① 힘 모으기(0.45초, 건물이 움츠렸다가 옆 건물로 내달린다, 모으는 소리) ② 부딪힘(맞닿은 채 0.1초 멈칫한 뒤 화면 크게 흔들기·흰 번쩍임·충격파 고리·불꽃·벽돌 파편·먼지구름·"쾅!", 쾅 소리와 센 진동) ③ 커지며 밀어내기(탄성 있게 한 번 넘쳤다 돌아오고, 옆 건물은 붕 떠서 빙글 돌며 멀리 날아가고 간판이 떨어지고 창문 조각이 튄다, 땅이 들썩인다, 와르르 소리) ④ 성장 축하(1.05초, 건물 뒤 빛줄기·둘레 반짝이·색종이(FxLayer 캔버스), 새 건물 이름이 크게 떠오르고(같은 건물 안이면 "확장 완료!") 고양이들이 뛴다, 축하 소리와 성공 진동) ⑤ 끝. 단계 시각은 `model.ts moveTimeline`. 효과는 카메라 축척을 되돌려 화면에서 늘 같은 크기로 그리고, 파편·조각은 SVG 요소 마흔 개 남짓이다. 화면을 누르면 끝 모습으로 건너뛰고 아래 버튼은 사무실로 간다. 등급이 내려가면 축하·소리 없이 예전처럼 짧게(1.5초) 끝난다. 확장을 사서 오른 때는 `useCompanyFx`의 등급 오름 팡파르·색종이를 내지 않는다(연출이 맡는다). 공사 기간은 없다(405번): 확장을 사면 곧바로 오르며 연출한다. 그 전에 시작한 공사만 연말 결산서를 닫은 뒤 완공 연출을 한다. 모션 줄이기면 연출 없이 끝 모습만 보인다.
- **앱의 다른 화면**은 웹 화면과 다르다. 웹(`frontend/`)은 공문서 한 장을 내리며 읽는 꼴이고, 앱은 위에 머리띠(건물·해·분기·자본), 가운데 장면 하나, 아래에 분기 넘기기 버튼과 다섯 탭(사무실·채용·배치·이슈·기록. 기록 탭은 380번에서 뺐다가 398번에서 되살렸다)이다. 바깥은 스크롤하지 않고 장면 안에서만 움직이며, 자리 고르기·자리 카드는 아래에서 올라오는 시트다. 채용은 뽑기·도감으로 나뉘고(직원 합성은 384번에서 뺐다), 뽑으면 카드가 하나씩 뒤집힌다(특급은 금빛으로 떨다가 늦게 열리며 화면이 번쩍이고 색종이가 터진다, 312번). 카드마다 등급 효과("맞히면 13.8배 · 방패")가 보이고, 결과 아래에 가장 높은 사람의 효과가 보인다(387번).
- **같은 것을 그대로 쓴다.** 앱은 `frontend/src`를 `@web/*`로 불러 API 클라이언트·게임 상태(스토어)·고양이 외형 정보·캐릭터 카드·회의 창(종목)·결산서·분기 실적·튜토리얼·자동 진행을 다시 만들지 않고 쓴다. 규칙은 서버에 있다.
- 세로 고정, 상태바 숨김(`styles.xml`), 안드로이드 뒤로 가기는 시트 닫기 → 사무실 탭 → 앱을 뒤로 보내기 순(`@capacitor/app`). 앱 안에서는 서비스 워커를 등록하지 않고 애드센스 광고를 그리지 않는다.
- **테마와 임팩트** (310번): 어두운 바탕 위에 종이빛 카드(카드 안은 웹과 같은 색이라 회의 창·결산서·캐릭터 카드가 그대로 맞는다), 아래 모서리가 두꺼운 게임 버튼(`.btn .btn-primary/-gold/-blue/-teal/-ghost/-line`), 장면은 탭 순서대로 옆에서 밀려 들어온다. `app/src/fx/`가 효과를 맡는다: `sound.ts`(화면 흔들림은 408번에서 모두 뺐다. Web Audio로 만든 톡·코인·금고·쿵·도장·팡파르, 건물 확장의 모으기·쾅·와르르·축하(399번), 머리띠의 스피커로 끄기), `haptics.ts`(Capacitor 햅틱, 브라우저는 vibrate), `fx.ts`+`FxLayer.tsx`(캔버스 위의 코인·색종이·불꽃·연기 터짐, 번쩍임, 떠오르는 글), `events.ts`+`useCompanyFx.ts`(서버 응답 전후를 견줘 자본 변화·뽑기·내보내기·분기 실적(폭락이면 화면 흔들림)·연말 결산·이사·랜드마크 타워(374번)·파산을 찾아 효과로). 머리띠의 자본은 숫자가 굴러간다(`useCountUp`).
- **멘탈 전투** (decisions.md 328번, [설계](./superpowers/specs/2026-11-07-mental-battle-design.md)): 스테이지 선택 시트에서 고른 판(번호 스테이지 또는 EX, 369번, 아래. 둘 다 멘탈벽을 지키는 디펜스다, 375번)으로 `app/src/mental/`의 창이 뜬다. 분기 넘기기 때 저절로 뜨지 않는다. 멘탈 카드 한 장을 고른 뒤, Phaser 3(`battle.ts`, `import()`로 늦게 불러 1.2MB 덩어리가 따로 간다)로 한 판(지금은 2분, 아래 참고)을 치르고(적을 물리치면 경험치가 쌓이고 레벨이 오를 때마다 멈춰 카드를 한 장 더 고른다, 330번. 플레이어는 두 장르 모두 아래에 붙박이로 서서 누른 쪽을 쏜다(걷지 않는다). 공격은 적이 플레이어를, 디펜스는 아래 멘탈벽을 노린다, 331·332번)(그림은 `art.ts`, 341번: 플레이어는 사장냥(크림색, 꾸밈 없음 345번, `@web/features/game/cat/draw`의 캔버스 그림)이고 든 무기(346번)는 두 앞발로 쥐어 겨누는 쪽으로 돈다. 적 넷·풀밭·나무·멘탈벽·탄도 같은 규칙으로 캔버스에 그려 Phaser 텍스처로 굽는다. 도트가 아니라 벡터라 pixelArt를 끈다) 결과를 `POST /api/company/stage`(EX는 `/api/company/ex`)로 보내고 받은 보상을 보인다. 보상과 분기 강화율은 서버가 정한다. 출전 전에 돌아갈 수 있다. 웹에는 없다.
- iOS는 아직 없다. `@capacitor/ios`를 더하고 `cap add ios`를 하면 같은 방식으로 붙는다(맥과 Xcode가 필요하다).

### 캐주얼 멘탈 스테이지 (361번)

- 실제 전장 자산: `app/src/mental/assets/{street,hero,enemies}.png`. 승인한 시안에서 이미지 생성 도구로 만든 전용 배경·투명 캐릭터이며, 생성 프롬프트는 같은 폴더의 `README.md`에 있다. Vite가 파일을 해시하고 APK와 `/app/` 산출물에 함께 넣는다.
- `art.ts`·`stageArt.ts`가 투명 여백을 제외하고 기존 크기에 맞춰 텍스처를 굽는다. `drawStageGun.ts`는 실제 무기의 종류·등급 및 두 앞발을 그린다. 멘탈벽은 실시간으로 밝기·균열·접촉 파동을 표시한다.
- UI는 `MentalWindow.tsx`·`stage.css`. 전투 위에는 흰 판이 없다(390번): 멘탈 게이지는 멘탈벽 그림 위에(`battle-wall`), 레벨·경험치(아래에서 위로 찬다)·처치 수는 왼쪽 가장자리에 세로로(`battle-level`), 시간·일시정지는 오른쪽 위 구석에, 보스 체력은 보스가 나올 때만 맨 위에 얇게 둬서 적이 내려오는 위쪽 가운데를 비운다. 결과 보고가 거절되거나 끊기면 결산으로 넘어가지 않고 재시도한다. 로딩 실패도 전투를 시작하지 않고 재시도/건너뛰기를 제공한다. 다른 앱 화면은 전투 중 `inert`로 처리하며 뒤로 가기와 Escape는 일시정지를 연다.
- 개발 서버(`pnpm dev --port 5182`)에서 `BROWSER_CHANNEL=msedge node scripts/stageCheck.ts`(크로미움 경로는 `CHROMIUM_PATH`)로 실제 Phaser를 실행한다. API만 가짜 응답이며, 무기 인벤토리에서 장비를 바꾼 뒤(403번) 스테이지 선택으로 1-1에 들어가 첫 카드 정지·전투 표시의 자리(390번)·데미지 숫자(391번, 개발 서버에서만 내보내는 `window.__mentalDamage` 집계)·레벨 1·2·3 마법(392번, `window.__mentalMagic`으로 레벨을 넣어 찍고 스스로 나가는지 검사)·뒷면 카드가 왼쪽부터 펼쳐지는지(393번, 시계를 멈춰 바뀔 때마다 찍음)·함께 싸우는 고양이 2~4마리(`window.__mentalMates`)·조준·벽 피격(벽 위 게이지가 준다)·일시정지·패배·보고 실패/재시도·두 장르·그림 재로딩·종료를 검증한다. Playwright의 시계로 프레임을 진행하며 `scripts/shots/stage/`에 캡처한다. Android 실기기 성능 검증은 별도다.

### 화면 개선 (2026-11-08)

- 라이벌 건물은 카메라 축척에 맞춰 양쪽 화면을 채우되 플레이어 건물과 일정한 골목 간격을 둔다. 다음에 밀어낼 라이벌 지붕 위에 목표 자본·부족 금액·공사 상태를 표시하며 누르면 확장 창을 연다.
- 인력 관리는 **"우리 사무실"**이다(decisions.md 412번, `StaffScene.tsx`·`staff-office.css`). 위에 제목과 자동 배치, 그 아래 알약 셋(근무 n / m자리 · 휴게실 n · 팀 분위기 한마디). 자리(데스크)마다 팀 방 카드가 있고, 방 안에는 벽·바닥과 긴 나무 책상에 고양이 직원(메인 거리와 같은 `toy-city/CatFigure.tsx`)이 모니터를 보고 앉아 있다. 이름표는 등급 방패와 이름이고, 팀장은 왕관·웃는 눈·짙은 정장에 말풍선 한마디(`staffLines.ts`, 사기·같은 자리 햇수·등급으로 고른다)를 한다. 머리줄 오른쪽 하트 다섯은 앉은 사람 사기의 평균, 둘째 줄은 원하는 능력치·자리 효과·지난 분기 팀 손익(`lastQuarter.reports`). 책상 한 줄에 넷까지, 넘으면 다음 줄 책상이다. 자리 수는 회사 전체라 빈 자리는 "+" 하나이고, "+"나 아래 "팀 보기 ›"를 누르면 팀 시트(빼기·팀장으로·앉힐 후보), 앉은 고양이를 누르면 직원 상세 시트가 뜬다. 맨 아래 휴게실 카드는 소파·화분·커피에 쉬는 동료가 졸고("z z"), 등급이 가장 높은 한 사람이 "저 일하고 싶어요…"라 한다. 누르면 보낼 팀을 맞는 순으로 고른다(`DeskButtons`). 고양이는 천천히 숨 쉬듯 들썩이고 모션 줄이기면 멈춘다. 끝난 회사는 보기만 한다(버튼 없음, 고양이를 누르면 상세만).
- 채용·기록은 색상 표지와 상태 요약을 사용한다. 종목 회의는 브리핑 표지, 의견 카드, 역할별 선택지로 구성한다. 결과 연출·토론을 건너뛰는 "빨리 보기"는 창 머리줄이 아니라 종목 차트(토론 중이면 토론 장면) 바로 밑의 큰 버튼이다(decisions.md 395번). 투자 결정 화면 위에는 이번 회의 수익률의 범위(−50% ~ +300%)와 띠를, 결과 화면의 회의 손익 위에는 실제 회의 수익률을 크게, 띠 위의 점과 맞힌 쪽·틀린 쪽 수익률을 보인다(`InvestReturn.tsx`, decisions.md 388번). 연말 결산서는 자본 증감·증감률·선두 팀·업적을 강조하고 확인 버튼을 하단에 유지한다. 분기 실적도 같은 종이(`report-paper.css`: 종이·둥근 테두리·그림자·소제목·하단 확인 버튼, 결산서와 공용)에 가벼운 표지(몇 년 차 몇 분기 + 네 칸 중 지금 분기)를 달고, 분기 말 자본과 늘고 준 몫을 크게 보인 뒤 돈의 흐름·팀별 성적·직원 소식을 번호 붙은 칸으로 나눠 짧게 차례로 드러낸다. 폭락 분기는 표지가 붉어지고 노랑·검정 경고 띠가 붙는다(decisions.md 396번). 두 결산서 모두 팀마다 팀장 등급을 눈에 띄는 방패(`GradeBadge size="md"`, 금부터 빛남)로, 팀원 등급을 작은 방패 줄로 붙이고, 연말 결산서에는 그해 등급이 오른 직원 칸(옛 등급 → 새 등급)이 있다(decisions.md 397번).
- 기록 장면(`RecordScene`: 지난 결산·업적·명예의 전당·연표, 263·309번)의 지난 결산 소식은 한 줄씩 카드로 보인다(398번): 왼쪽 띠 색과 동그란 아이콘, 작은 꼬리표(시장·조짐·채용권·성장·등급·실수·인사·건물·시대·자본·멘탈·소식)로 갈래를 알리고, 첫 줄(그해 시장)은 굵은 머리 카드다. 서버의 소식은 갈래 없는 문장이라 앱이 낱말로 가른다(`scenes/news.ts`, 맞는 갈래가 없으면 '소식'). 연말 결산서를 닫으면 기록 탭으로 간다.
- 멘탈 전투는 항상 한 방향으로 한 발씩 발사한다. 총알 강화 단계(최대 3단계, 단계마다 탄 위력 계수 +40%p·크기 +20%p)는 이제 무기만 가진다(산탄총 2). 카드로는 오르지 않는다(377번). 무기 수치는 탄 갈래 대신 **탄 강화 단계 `power`**(산탄총 2)다. 명중 시 폭발 링·섬광·불꽃이 나타나며 강화 단계에 맞춰 커지고, **2단계부터는 주변 적도 맞은 피해의 50%를 입는다**(decisions.md 362번). 무기마다 효과가 하나씩 있다: 권총 기본·리볼버 치명타·기관단총 둔화·산탄총 폭발·소총 관통(376번, `weaponEffects.ts`).
- 적이 피해를 받으면 **언제나 데미지 숫자**가 뜬다(391번, `damageNumbers.ts`): 한 방에 죽는 적·마지막 한 방·화상 틱·번개 튐까지. 총알 흰색, 리볼버 치명타는 금빛 글자에 빨간 윤곽으로 크게, 마법은 물 파랑·불 주황·번개 노랑, 화상은 0.5초마다 작게. 같은 적의 같은 피해는 0.15초 안이면 하나로 합치고 새 숫자는 살짝 흩뿌리며, 0.4~0.6초에 떠오르며 사라진다. 숫자 텍스트는 풀(36+치명타 8)로 돌려 쓴다. 숫자를 띄우는 곳은 `battle.ts`의 `damageNumber(적, 피해, 종류)` 하나다.
- 디펜스 스테이지는 뒤로 갈수록 적 체력·수·빠르기·멘탈 피해가 함께 오르고(스테이지마다 +90%·+20%·+6%·+20%, `advance.ts` `STAGE_STEP`), 그 배율은 판 안에서 15%부터 70초에 걸쳐 끝까지 걸린다(404번). 1-3까지는 강화 없이 깨고 1-4부터 강화·무기가 필요하다. 개발 서버에서 `node scripts/balanceCheck.ts`(STAGES·RUNS·WEAPON·UPGRADE)로 실제 판을 손대지 않고 돌려 깼는지·별·남은 멘탈·처치 수를 잰다.
- 한 판은 **2분**이다(363번). 멘탈 전투는 **스테이지를 골라서** 한다(369번): 분기 넘기기 때 저절로 뜨지 않고, 메인의 스테이지 버튼이 스테이지 선택 시트(챕터를 ‹ ›로 넘겨 보는 n-1…n-10, 별, 잠김, EX 디펜스)를 연다. 챕터는 다섯이고 챕터 보스(n-10)를 깨면 다음 챕터가 열린다(407번). 번호 스테이지는 **전진 모드**(364·365번, `advance.ts`): 위로 올라가는 세로 스크롤, 끌어서 움직이고 총은 자동 조준, 구간마다 길막 적을 다 잡아야 다음 구간이 열리고 1-10에는 보스 패닉셀 대장. 2분 안에 못 깨면 실패, 결과에 별 3개와 받은 보상. EX 디펜스(분기에 한 번)는 멘탈벽 뒤 붙박이(`mode: 'defense'`). 분기 강화율은 깬 최고 스테이지 × 3%(최대 30%)로 매 분기 저절로 붙는다.
- 무기는 전투에서 떨어지지 않고 **무기 뽑기권**으로 뽑는다(366번). 장착·뽑기·합성은 메인 오른쪽의 **무기** 메뉴가 여는 무기 인벤토리 시트에서 한다(403번, `WeaponInventory.tsx`): 든 무기를 크게, 가진 무기를 등급 높은 순으로 보이고, 같은 무기 둘을 합쳐 한 등급 올린다. 스테이지 출전 화면에는 든 무기 한 줄과 "무기 바꾸기"(인벤토리로)만 있다.
- 무기마다 쏘는 방식이 다르다(402번, `weaponEffects.ts`의 `FIRE_STYLES`): 권총 고른 한 발, 리볼버 묵직한 한 발(굵은 탄·큰 화염·화면 울림), 기관단총 흩뿌리는 연사(±5도), 산탄총 굵은 산탄 한 덩이(부채꼴 불꽃·펌프 소리), 소총 길고 곧은 탄(촘촘한 꼬리). 탄은 늘 한 줄에 한 발이고 판정 크기는 같다.
- 메인 화면 아래 칸은 **강화 · ▶ 넘기기 · 스테이지**다(367번). 강화 시트(`toy-city/BattleUpgrades.tsx`)에서 자본으로 공격력·연사·체력(최대 멘탈, 410번)을 최대 단계 없이 한 단계에 +1%씩 올리고(값은 1b에서 단계마다 4%씩, 고양이 속도 강화는 뺐다), 멘탈 전투의 바탕 수치에 영구로 붙는다. 한 번 누르면 한 단계, 꾹 누르고 있으면 0.4초마다에서 점점 빨라져 0.05초마다 오르고 손을 떼거나 자본이 모자라면 멈춘다. 요청은 한 번에 하나만 보내고 그사이 누른 단계는 "n단계 올리기"로 묶는다(`upgradeQueue.ts`, decisions.md 394번).
- 멘탈 카드에는 등급이 있다(377번): 일반은 공격력 +10%·공격 속도 +10% 둘뿐이고, 희귀·영웅·전설은 물·불·번개 마법이다(희귀에는 "고양이 한 마리 더"도 있다, 393번). 칸마다 45%로 마법 카드가 나온다. 카드 테두리와 배경이 등급마다 다르다(희귀 파랑, 영웅 보라 빛과 반짝임, 전설 흐르는 금빛 테두리와 맥박치는 빛).
- 마법은 **총알과 따로 제 주기에 스스로 나간다**(392번, `magic.ts`). 처음 고르면 Lv.1, 같은 마법을 또 고를 때마다 한 레벨씩(최대 Lv.5) 오르고, 마법 카드의 등급은 그 카드로 오르는 레벨이다(Lv.1 희귀·Lv.2 영웅·Lv.3부터 전설). 카드에 "Lv.2 → Lv.3"이 보인다. 물은 가장 가까운 적에게 물방울 → 꿰뚫는 물줄기 → 넓어지는 큰 물결(느리게), 불은 몰린 곳에 불씨 → 불덩이 → 불기둥 폭발(둘레 화상, 불길이 남음), 번개는 체력이 가장 많은 적에게 가는 줄기 → 굵은 번개 → 여러 갈래(옆 적으로 차례로 튐). 레벨마다 쿨다운·피해·범위가 좋아지고 피해는 마법 배율 × 지금 공격력이다. 배우거나 레벨이 오르면 곧바로 한 번 나간다. 쏘는 주체(`MagicCaster`)는 사장냥에서 떨어져 있어 여러 고양이가 같은 마법을 쓸 수 있다. 탄·불길·줄기·빛은 풀로 돌려 쓰고 파티클 수를 묶는다.
- 강화 카드 선택은 등급·역할 배지·큰 아이콘·효과 영역·선택 반짝임을 사용한다. 전장을 가리지 않도록 막은 투명하고, 세로로 긴 카드 석 장을 화면 아래에 가로로 나란히 둔다(decisions.md 373번). 좁은 화면과 모션 줄이기를 지원한다.
- 카드 석 장은 **뒷면으로** 쿵 깔리고 왼쪽부터 한 장씩 떨며 빛이 새다가 뒤집힌다(393번, 순서는 `cardReveal.ts`). 등급이 높을수록 세다: 일반 탁, 희귀 파란 빛·반짝이, 영웅 보라 빛기둥·화면 번쩍·진동, 전설은 화면이 어두워지며 뜸을 들였다가 금빛 폭발·빛줄기·크게 흔들림·큰 효과음. 뒷면 테두리가 등급을 살짝 흘린다. 뒤집히는 속도는 모든 등급이 같다(400번). 다 펼친 뒤에만 고르고, 그 전에 누르면 남은 카드를 한 번에 펼친다. 다 펼친 뒤 5초 안에 고르지 않으면 등급이 가장 높은 카드를 저절로 고른다(401번: 그 카드에 점선 테두리, 아래에 줄어드는 막대). 움직임 줄이기면 처음부터 앞면이다. 버튼의 `data-face`(back·tease·turn·front)와 묶음의 `data-revealed`로 상태를 읽는다.
- 희귀 카드 **"고양이 한 마리 더"**(393번)를 고르면 사장냥과 똑같이 센 고양이가 멘탈벽 뒤 같은 줄에 한 마리씩(최대 3마리) 선다(`mates.ts`, 그림은 `art.ts` `bakeMates`: 사장냥 그림에 색만 섞음). 같은 수치로 같은 곳을 저마다 쏘고, 저마다 시전자를 가져 같은 마법을 쓴다. 칸마다 8%(다 차면 일반 카드), 마법 45%, 나머지 일반.
- 적은 8프레임 보행으로 좌우 발·몸 기울기·착지 그림자가 움직인다. 종류별 속도에 맞춰 발걸음을 바꾸며, 개체마다 시작 발을 다르게 둔다. 보행은 텍스처 안에서만 변형해 이동 경로와 충돌 원을 유지한다. 전투 시간으로 진행해 일시정지 뒤 이어지며 모션 줄이기에서는 정지 자세를 쓴다.

## 2. 화면을 어디서 가져오나

| 방식 | 언제 | 설정 | 서버 |
|---|---|---|---|
| **운영 웹의 /app/ 띄우기** (기본) | `CAP_SERVER_URL`이 없거나 주소일 때 | 앱 화면은 웹과 같이 배포되어 `https://game.kwaklabs.com/app/`에 있다(deploy.yml이 `app/dist`를 `web/app/`에 둔다). 앱은 그 주소를 WebView에 띄운다. 화면이 배포될 때마다 앱도 새 화면이다 | 손댈 것 없다. API와 세션 쿠키가 웹과 같은 출처다 |
| **화면 담기** | Run workflow의 `server_url`에 `none` | `app/dist`를 APK 안에 담는다. 앱의 출처는 `https://localhost`이고 API는 `VITE_API_BASE`(저장소 변수 `APP_API_BASE`)로 간다. 화면을 바꾸면 앱을 다시 내야 한다 | 다른 출처에서 부르므로 CORS와 쿠키를 열어야 한다: 환경 변수 `API_CORS_ORIGINS=https://localhost`, `SESSION_COOKIE_SAME_SITE=None` |

폰 브라우저로 `https://game.kwaklabs.com/app/`을 열면 앱과 같은 화면이 나온다(설치 없이 확인할 때).

## 3. 개발

```bash
cd frontend && pnpm install          # 앱이 frontend/src를 쓰므로 웹의 의존성이 있어야 한다
cd ../app && pnpm install
pnpm dev                             # http://localhost:5173/app/ (API는 localhost:8080으로 프록시)
pnpm check && pnpm exec tsc -b && pnpm test && pnpm build
```

서버 없이 화면만 보려면 `pnpm dev`를 띄운 채 `CHROMIUM_PATH=/경로/chrome node scripts/shot.ts`(가짜 회사 `scripts/fixture.ts`로 모든 장면을 `scripts/shots/`에 찍는다. `EMPTY=1`이면 회사가 없을 때 처음 들어가는 모습).

토이시티 회귀 확인: 개발 서버를 띄운 뒤 `node scripts/toyCityCheck.ts`. `APP_URL` 기본값은 `http://127.0.0.1:5182/app/`, 설치된 Edge를 쓰려면 `BROWSER_CHANNEL=msedge`. API를 가짜 응답으로 대체해 서버 거절·공사 시작·다섯 번의 좌우 교대 확장(첫 확장은 힘 모으기·쾅·밀어내기·축하 장면을 `expansion-0~3-*.png`로 찍고, 둘째는 화면을 눌러 건너뛴다)·움직임 줄이기면 연출 없이 끝 모습·실제 직원 수·탭 이동·시트 키보드 포커스·화면 폭을 확인하고 `scripts/shots/toy-city/`에 캡처한다. 서버·DB 연동 검증은 GitHub CI의 E2E가 맡는다.

앱 화면을 고칠 때: 규칙·숫자·문구가 웹과 같아야 하는 것(회의 창, 결산서, 그림)은 `frontend/src`를 고친다(웹과 앱 둘 다 바뀐다). 틀·탭·시트·장면은 `app/src/app/`을 고친다.

## 4. APK 만들기

### GitHub Actions (권장)

`.github/workflows/android.yml`. Actions 탭 → **Android** → Run workflow. 아무것도 넣지 않으면 운영 웹의 앱 화면을 띄우는 APK가 나온다. `app/`이나 `frontend/src/`가 바뀐 PR과 main에서도 돈다.

| 저장소 설정 | 뜻 |
|---|---|
| 변수 `APP_SERVER_URL` | 앱이 띄울 주소를 운영 웹이 아닌 곳으로 바꿀 때 |
| 변수 `APP_API_BASE` | 화면 담기일 때 API 주소 |
| 시크릿 `ANDROID_KEYSTORE_BASE64` `ANDROID_KEYSTORE_PASSWORD` `ANDROID_KEY_ALIAS` `ANDROID_KEY_PASSWORD` | 있으면 서명한 배포용 APK도 만든다. 없으면 디버그 APK만 |

결과는 실행 결과의 Artifacts에서 `app-debug`(폰에 바로 설치), `app-release`(서명 키가 있을 때)를 받는다. 디버그 APK는 Play 프로텍트가 "잠재적으로 유해한 앱"이라 경고한다: 모르는 출처의 앱이라 그런 것이고 "무시하고 설치"·"닫기"로 지나간다. 경고를 줄이려면 고정 서명 키를, 없애려면 Play 콘솔 내부 테스트 트랙을 쓴다.

### 내 컴퓨터

Android Studio(또는 안드로이드 SDK와 Java 21)가 있어야 한다.

cd app

## 5. 스토어에 올리려면 (아직 하지 않았다)

- 서명 키를 만들고 시크릿을 넣는다. `versionCode`·`versionName`은 `app/android/app/build.gradle`에서 올린다.
- Play 스토어는 APK가 아니라 **AAB**를 받는다: 워크플로의 `assembleRelease`를 `bundleRelease`로 바꾸면 `app/build/outputs/bundle/release/app-release.aab`가 나온다.
- 개인정보처리방침 주소(웹의 `/privacy`)를 스토어 등록 정보에 적는다.
- 시즌·친구·라이벌처럼 앱에서만 붙일 것은 증권사 육성 설계 10절에 있다. 아직 정하지 않았다.
- **종목 회의 뒤 전투** (decisions.md 413·414번): 회의 결과 화면에서 틀린 쪽에 걸었으면 디펜스로 손실을 줄이고, 맞힌 쪽이면 공격 판(큰 덩어리 매도벽을 부수고 오르기, 좌우로만 이동, 416번)으로 수익을 키운다. 별에 따라 회의 손익이 바뀌고(`POST /api/company/invest/battle`), 끝나면 회의 창으로 돌아와 전·후 손익을 보이고 분기를 넘긴다. 건너뛰면 손익 그대로다.
- **확장 끝 모습과 새 라이벌** (decisions.md 415번): 확장 연출은 밀어낸 쪽을 "매물" 팻말이 선 빈자리로 끝낸다. "사무실로"를 누르면 사무실 거리에서 그 자리에 새 라이벌 회사가 한 층씩 밑에서 위로 지어지고 간판이 걸린다(한 번만, 움직임 줄이기면 바로 서 있다).
- **글자 크기 고정** (decisions.md 417번): 안드로이드 앱은 휴대폰 글꼴 크기 설정과 상관없이 디자인한 크기로 보인다(`MainActivity`의 `setTextZoom(100)`).
