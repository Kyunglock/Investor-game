# 주거·부동산 설계

> 상태: 1·2단계 구현됨 (2026-10-19) · 결정 기록: [decisions.md](../../decisions.md) 40·42번
> 사용자: "부동산 투자도 해야 하고 전반적으로 한국 사회를 배경으로 해야 해. 부동산 투자하면 빚도 생기겠지, 주담대 6%대일 거고. 현실적이고 개연성 있게."
> 사용자 답: 결혼·자녀·집값 급등 같은 때 "집 살까?" 이벤트. LTV 50%·주담대 이자 6%처럼 현실적인 기준으로 자산이 있어야 산다. 아니면 전세든 월세든 산다. 빌라 전세는 보증금 사기 확률을 넣어 파산 루트를 만든다. 부동산은 언제든 사고팔 수 없다: 사는 사람이 나와야 팔린다. 부동산은 아파트로만. 금리는 경기 따라 변동, LTV·DSR 적용, 2채까지. 주거 단계·청약·생활 이벤트 한국화.

## 1. 단계

| 단계 | 내용 |
|---|---|
| 1 | 주거 형태(월세·빌라 전세·아파트 전세·자가), 아파트 시세(서울·경기), 변동 금리, 주담대(LTV·DSR), 전세대출, 전세사기·보증보험, 집 사기 이벤트, 매수자가 나와야 팔리는 매도, 갭투자 2채 |
| 2 | 청약(가점·당첨), 한국식 생활 이벤트(명절·학원비·경조사·부모님) |

## 2. 도메인

- **시장**이 아파트 시세 지수(서울·경기)와 월별 주담대 금리를 소유한다. 경기 흐름(decisions.md 38번)을 이미 알고 있어서다. 위기 때 집값은 주식보다 덜, 느리게 빠지고(갈래별 `realEstatePercent`) 금리는 오른다.
- 새 도메인 **주거**(`housing_`)가 거주 형태·보증금·임대 만기·보유 주택·주담대·전세대출·매물 상태를 소유한다. 가격은 모른다: 진행이 시장에서 읽어 넘긴다.
- **자산**의 빚(마이너스 통장)과 주거의 대출은 따로다. 총자산 = 자산의 총자산 + 집 시세 + 보증금 − 주담대 − 전세대출.
- **가계**의 생활비에서 주거비를 뺀다(1인 140만 → 90만, 부부 220만 → 150만). 주거비는 주거가 따로 계산한다.

## 3. 수치 (초기값, 25세 기준, 물가 연 2%)

| 항목 | 값 |
|---|---|
| 서울 아파트(84㎡) 시세 | 15세 6.1억(25세 약 10억), 추세 연 5%, 월 잡음 ±1% |
| 경기 아파트(84㎡) 시세 | 15세 4억(25세 약 6억), 추세 연 4%, 월 잡음 ±1% |
| 아파트 전세가 | 시세 × 55% |
| 빌라 전세 보증금 | 경기 아파트 시세 × 30% (1인) / × 40% (부부·자녀) |
| 월세 | 보증금 1,000만 + 월 60만 (1인) / 2,000만 + 90만 (부부·자녀). 보증금이 모자라면 모자란 만큼 × 월 0.5%를 월세에 얹는다(전월세 전환) — 월세는 언제나 구할 수 있다 |
| 주담대 금리 | 기준 연 5.5%, 위기로 빠지는 동안 +1.5%p, 회복기 −1.0%p, 달마다 ±0.25%p 잡음(기준으로 되돌아감), 3.0~8.0% |
| 주담대 | LTV 50%(첫 집), 30년 원리금균등, 금리는 달마다 바뀐다 |
| DSR | 연 원리금 ≤ 연 소득(월급 + 배우자) × 40%. 전업투자자는 소득이 없어 대출이 안 된다 |
| 전세대출 | 보증금의 80%까지, 금리 = 주담대 − 0.5%p, 이자만 |
| 전세사기 | 빌라 전세 만기 때 7%로 보증금을 못 돌려받는다. 보증보험(연 보증금의 0.2%)에 들었으면 돌려받는다 |
| 갭투자 | 집이 1채일 때만. 시세의 55%는 세입자 보증금, 나머지 45%는 현금. 대출 없음. 만기 때 역전세(전세가가 내렸으면 차액을 돌려줘야 함) |
| 매도 | 매물로 내놓으면 달마다 매수자가 나올 확률 25%(위기로 빠지는 동안 5%, 1년 새 15% 넘게 오르면 45%). 팔리면 시세 − 대출(갭이면 − 세입자 보증금) |

## 4. 이벤트 (`HOUSING`)

| 정의 | 언제 | 선택지 |
|---|---|---|
| `move-out` | 처음 일을 시작할 때(독립) | 월세 / 빌라 전세 / 빌라 전세 + 보증보험 / 아파트 전세(감당되면) |
| `lease-end` | 세입자로 2년마다 | 연장(보증금·월세 +5%) / 다른 형태로 이사 / 집 사기(감당되면) |
| `cheongyak` | 집이 한 채도 없을 때 독립 1년 반 뒤부터 1년 반마다 | 청약을 넣는다(가점으로 당첨, 분양가 = 서울 시세 70%, 당첨돼도 계약금이 모자라면 포기) / 넘긴다 |
| `buy` | 결혼·출산 직후, 서울 시세가 1년 새 15% 넘게 오를 때(최소 2년 간격) | 서울 아파트 / 경기 아파트(감당되면) / 갭투자(1주택이면) / 안 산다 |
| `spouse-rent` | 결혼한 뒤 월세에 살면 결혼(독립) 1년 뒤, 그 뒤로도 월세면 1년 반마다(아이가 태어나면 반년 뒤로 앞당김), 60세까지 (#116, decisions.md 99번) | 빌라 전세 / 보증보험 / 아파트 전세 / 서울·경기 매수(감당되면) / 조금만 더 모으자고 설득한다 / 그냥 월세에 산다. 단계(물은 횟수)마다 문구가 세지고 미루거나 거스르면 행복도·가족 점수가 깎인다 |

"감당되면"은 계약금(시세 − 대출 가능액)과 DSR을 모두 넘는지다. 감당 안 되는 선택지는 이유와 함께 막아서 보여 준다.
