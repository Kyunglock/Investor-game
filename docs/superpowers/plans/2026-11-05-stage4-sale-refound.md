# 4단계: 매각과 재창업

> 설계: [증권사 육성 설계](../specs/2026-11-05-brokerage-raising-design.md) 9절
> 구현한 결정: [decisions.md](../../decisions.md) 215~218번
> 앞 단계: [3단계 회사 건물·객장 그림과 직원 차림새](./2026-11-05-stage3-office-art.md)

## 흐름

```
1호 회사(평범한 시대) ─ 세 해 ─→ 시대 끝: 반드시 판다 ──┐
        └ 그 전이라도 SSS 이상이면 스스로 판다 ───────────┤
                                                          ↓
              명성 +점수 → 공동창업자 고르기(명성만큼) → 2호 회사(다른 시대, F, 시작 자본 +명성 혜택)
```

## 서버

- `CompanyState`: 회사 번호, 시대, 팔렸는가, 차릴 때의 한 줄
- `RaisingMemory`: 사장 명성 점수, 판 회사 수 (세션 단위)
- `CompanyEngine.refound`: 팔고 새 회사를 차린다. `canSell`·`fameFor`·`fameGrade`·`cofounderSlots`
- `POST /api/company/sale {cofounders}`: 응답은 새 회사

## 화면

- 회사 화면 위: 시대 이름과 설명, 사장 명성, 차릴 때의 한 줄
- 시대가 끝나면 매각 패널이 바로 열린다(공동창업자 고르기). 그 전에 팔 수 있으면 "회사 팔기" 버튼

## 남은 것

- 자본 띠와 매출 배율을 시뮬레이션으로 맞추기 (설계 5절 1·2번). 지금은 1억 원에서 SSS에 닿지 않는다
- 명성 혜택의 첫 운용금·사수 효과, 시대별 섹터 비중
