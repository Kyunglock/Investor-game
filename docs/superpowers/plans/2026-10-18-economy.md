# 월 단위 시장·종목, 가계부, 자유 매매 화면 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 섹터 아래 가짜 이름의 종목 18개가 매달 가격이 움직이고, 보유는 수량×현재가로 평가되며, 월급에서 생활비·결혼·자녀 비용이 나가고(모자라면 빚), 플레이어가 아무 때나 멈추고 종목을 사고팔 수 있는 투자 화면을 만든다.

**Architecture:** 새 도메인 둘을 더한다. **시장(market)** 은 종목 가격과 월별 이력을 소유하고 매달 추세+잡음으로 움직이며 뉴스 충격을 받는다(콘텐츠 `stocks.json`을 직접 읽는다). **가계(household)** 는 결혼·자녀·은퇴 상태와 월 지출·배우자 소득 계산을 맡는다. **자산(asset)** 은 섹터 평가액 대신 종목 수량·원가와 빚을 다루고, 가격은 인자로 받는다. 이벤트는 `LIFE`(결혼·자녀 선택형)와 `NOTICE`(지출 알림, 멈추지 않음)를 더하고 뉴스에 종목을 붙인다. **진행** 이 매월 1일마다 시장→수입→지출→이자 순서로 조율하고, 자유 매매 엔드포인트를 연다. 클라이언트는 포트폴리오·시장 패널·가계부·토스트를 더하고 30일마다 보고한다.

**Tech Stack:** Java 21 / Spring Boot 4 / JdbcClient / Flyway / Testcontainers · React 19 / TypeScript / Zustand / Tailwind v4 / Vitest / Playwright · OpenAPI 3.1

**Spec:** `docs/superpowers/specs/2026-10-18-economy-redesign-design.md` 5~13절 (4절은 별도 계획 `2026-10-18-trait-scenes.md`가 맡는다. 이 계획은 그 계획이 끝난 뒤 실행한다.)

## Global Constraints

- 수치는 설정(`application.yml`)·콘텐츠에서 읽는다. 금액 `long`(원), 비율 만분율 `int`, 0 방향 버림, 부동소수점 금지.
- 난수는 판 시드에서 `SeededRandom.forKey(...)`로 유도하고 **뽑는 순서를 고정**한다. 같은 상태에서 다시 불러도 같은 결과(멱등).
- 진행만 다른 도메인을 부른다. 직접 호출 허용은 **이벤트→콘텐츠, 시장→콘텐츠** 둘. `DomainBoundaryTest`·`MigrationRulesTest`의 도메인 목록에 `market`, `household`를 더한다.
- 응답에 숨은 값(방향·폭·시드·다음 달 변동) 금지. `GameFlowTest`가 `seed/hidden/magnitude/truth` 문자열을 검사한다.
- 마이그레이션 `V<yyyyMMddHHmm>__<도메인>_<설명>.sql`, FK 금지, 테이블 접두사 = 도메인. 운영 데이터가 없으므로 `asset_holding`은 drop·create 해도 된다.
- 종목 이름은 실제 상호와 같지 않은 패러디. 상표·로고 금지.
- 뉴스는 스킵 불가. 자유 매매는 용기 판정만, 뉴스는 전체 판정.
- 기존 E2E `data-testid`(`total-asset`, `cash`, `event-card`, `outcome-card`, `outcome-actions`, `hint`, `age`, `nickname`, `job`, `style`, `stat-*`, `life-log`, `life-log-line`, `identity-card`, `asset-curve`, `reported-day`)와 버튼 문구(`매수`, `투자를 시작한다`, `멈춤`, `계속`, `다시 시작`) 유지.
- 서버 `./gradlew spotlessApply test`, 웹 `pnpm check && pnpm exec tsc -b && pnpm test`, E2E `pnpm e2e`. 커밋 메시지 한글, `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- 1개월 = 30일, 1년 = 360일 (`GameProperties`). 월 번호 `m = day / 30`.

## Review Focus

- 현금 0, 빚 있는 상태에서 생활비 지출: 빚만 늘고 현금은 0 그대로, 이자는 늘어난 빚에 다음 달 붙는다 (Task 3 테스트).
- 가격 100원 종목에 −99% 충격: 바닥 `min-price`에서 멈추고, 보유 평가액도 0 아래로 가지 않는다 (Task 2 테스트).
- 수량이 보유보다 큰 매도 요청: 전량 매도로 처리하고 원가가 0이 된다 (Task 3 테스트).
- 매매 요청이 대기 중 이벤트가 있는 판에 오면 400이고 자산이 변하지 않는다 (Task 9 테스트).
- 보고를 한 번에 360일(12달) 뛰어도 12달 가격·12번 월급·12번 지출이 정확히 한 번씩 처리되고, 같은 날을 두 번 보고해도 중복되지 않는다 (Task 8 테스트).
