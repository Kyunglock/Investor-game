# 1단계: 3분 육성 한 판

> 설계: [증권사 육성 설계](../specs/2026-11-05-brokerage-raising-design.md) 3·11절, [투자 원칙 장치·단서 기사 설계](../specs/2026-11-05-investment-principles-design.md) 1~3절
> 구현한 결정: [decisions.md](../../decisions.md) 197~207번
> 다음 단계: 2단계 아주 작은 회사(자리 2개, 배치, 턴 3번, 결산) → 3단계 회사 건물·객장 그림과 직원 차림새 → 4단계 매각과 재창업

## 1. 빠지는 콘텐츠

새 육성 판에서 쓰지 않는다. 옛 코드와 콘텐츠 파일은 이 단계에서는 지우지 않고 화면에서만 끊는다(2절 끝).

| 묶음 | 무엇 |
|---|---|
| 나이·시계 | 1세 → 65/70세 진행, 클라이언트 시계·배속·자동 진행, 단계(성장기·저축·투자), 투자 시작 제안 |
| 일 | 직업·월급·연차·이직, 직장 장면(`careers.json` 378장), 전업투자자 |
| 일상·가족 | 성인 일상(`daily.json` 328장), 결혼·배우자·자녀·자녀 결혼·가족 여행·집들이·나들이·아르바이트(`life.json` 전체), 은퇴·연금 |
| 주거 | 월세·전세·청약·주담대·집 매물(`homes.json`, housing 도메인) |
| 점수 | 행복도·가족 점수, 위로 문구 |
| 화면 | 출생 신고서, 가계부 수첩, 인생 지도, 엔딩 크레딧, 인생 기록부, 자유 매매창, 순위표 |
| 성향 장면 | 15~24세에 묶인 `traits.json` 282장 → 나이 없는 성향 카드 8장을 새로 썼다(`raising.json`) |

남기는 것: 뉴스 정의 23개(문장 풀로 재조립), 종목 18개·섹터 6개, 위기 갈래와 전조 문구, 판정 규칙(줏대 → 인내심/용기), 힌트 문구(형광펜 옆 메모), 등급 띠(24번), 공유 링크 페이지(옛 판).

## 2. 서버 구조

- 옛 진행 엔진은 "시각 보고 → 그 사이의 월급·시세·이벤트 계산"이라 카드 12장 판에 맞지 않는다. **새 도메인 `raising`**을 만든다.
  - `RunEngine`: 카드를 펼치고(성향·뉴스·원칙·풀기·큰일·빚내서 사기·심사), 판정하고, 시장을 한 장만큼 움직인다. DB와 시각을 모른다.
  - `raising_run.state`: 판 상태 JSON 한 칸. `raising_memory.state`: 세션이 판을 넘어 기억하는 것(열린 기능, 본 설명, 단골 인물 횟수, 판 수).
  - 행동 도메인의 판정·형광펜·운 규칙을 그대로 쓰고, 장치가 막는 단계만 `ChoiceContext.Guards`로 넘긴다.
- API: `POST /api/runs`, `GET /api/runs/current`, `POST /api/runs/{runId}/choose {card, option}`. 응답의 능력치는 등급만.
- 옛 `/api/games`와 그 도메인들은 남긴다(공유 페이지·관리자 기록·봇이 쓴다). 지우는 것은 따로 정리 PR로 한다.

## 3. 화면 구조

```
시작(수습 시작) → 카드 한 장씩 ─┬→ 결과 카드(맞대결 막대, 고른 대로 했다면 / 실제로는, 단골 인물, 복기) → 다음 카드
                                └→ 입사 심사 결과(종합 등급, 등급 사다리, 다섯 능력치 등급) → 다음 사람 키우기
```

- 위쪽: 수습 기간 n / 12, 총자산과 수익률, 다섯 능력치 등급, 현금·빚·보유, 걸어 둔 원칙과 그 대가.
- 뉴스 카드: 문장 4개의 단서 기사, 형광펜과 여백 메모, 단골 인물의 꼬드김, 폭락 조짐(빨간 글씨). 맞출 확률은 보이지 않는다.
- 처음 온 사람(11.1절): 사기·지켜보기만 → 주식이 생기면 팔기 → 첫 뒤집힘에 한 줄 설명 → 안목이 처음 오르면 형광펜 → 그다음 뉴스부터 조금/크게.

## 4. 남은 것

- 관리자 플레이 기록에 육성 판 보이기 (지금은 서버 로그의 `run-card` 줄로 본다)
- 위기 전조 돌아보기 한 줄 (투자 원칙 장치 설계 3.3절)
- 옛 인생 시뮬레이터 코드·콘텐츠 정리
