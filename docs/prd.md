# PRD: 투자자 시뮬레이터 (Investor Game)

> 상태: 초안 v0.1
> 표기: 대화에서 확정된 내용은 그대로 쓰고, 제안·가정은 **(추측)** 으로 표시한다. 핵심 루프의 상세 수식은 [poc.md](./poc.md)를 따른다.

## 1. 개요

뉴스 이벤트를 보고 매수·매도·관망을 고르며 자산을 불리는 투자자 시뮬레이터. 이 게임의 특징은 **사용자의 선택이 그대로 실행되지 않는다**는 점이다. 캐릭터의 능력치(인내심, 용기, 줏대 등)에 따라 선택이 확률로 뒤집힌다.

## 2. 목표 / 비목표

**목표**

- 사용자는 투자로 자산을 불리는 것을 목표로 한다.
- 선택이 뒤집힐 때 **억울함**을 느끼고, 그 억울함이 **능력치를 키워서 극복하고 싶다**는 동기로 이어진다.
- 억울함에는 반드시 원인이 보여야 한다. 원인이 없는 억울함은 이탈로 이어진다.
- 뒤집힘은 손해만 주지 않는다. 용기가 부족해서 못 산 종목이 폭락하는 것처럼 득이 되는 경우도 있다.

**비목표 (현재 버전)**

- 실제 시세·실제 뉴스 연동 (추측: 가상 이벤트만 사용)
- 실제 투자 조언이나 교육 목적의 정확성
- 멀티플레이, 계정·로그인. 계정 없이 익명 세션만 쓴다. (확정)

**안티 목표** (기술적으로 동작해도 실패인 경우)

- 뒤집힘의 원인을 알 수 없어서 "그냥 랜덤이네"로 느껴지는 경우
- 능력치를 키워도 아무 변화가 느껴지지 않는 경우

## 3. 핵심 게임 흐름

```
① 캐릭터 생성 (랜덤)
   → ② 직업 선택 이벤트
   → ③ 저축 단계 (월급으로 자산 모으기 + 성향 형성 이벤트)
   → ④ "투자를 시작해보겠다" 전환
   → ⑤ 핵심 루프: 뉴스 이벤트 → 매수 / 매도 / 관망
```

### 시간 흐름과 종료 (확정, 80억 분의 1 벤치마킹)

- 게임 시간은 **실시간으로 흐른다.** 캐릭터의 나이가 계속 올라간다.
- 이벤트는 발생하면 알려 준다. 알림성 이벤트는 사용자가 **스킵할 수 있다.**
- **뉴스 이벤트는 선택의 순간이므로 스킵할 수 없다.** 매수·매도·관망 중 하나를 골라야 한다. 관망도 선택이다.
- (추측) 선택해야 하는 이벤트가 떠 있는 동안에는 시간이 멈춘다. 80억 분의 1에서 결정 시점에 시간이 멈추는 것과 같다.
- (추측) 직업 선택 같은 선택형 이벤트도 뉴스와 같이 스킵할 수 없다. 스킵할 수 있는 것은 선택이 필요 없는 알림성 이벤트(성장, 생활 소식 등)다.
- **종료 조건은 나이**다. 정해진 나이에 도달하면 한 판이 끝나고 최종 결과를 보여 준다.
- **한 판 길이는 10분으로 가정**한다.
- (추측) 시작 나이는 사회 초년생 시기(20대 중반), 종료 나이는 은퇴 시기(65세 안팎)로 두면 약 40년이고, 10분이면 1년이 약 15초다. 나이 범위와 속도는 체감 테스트 후 조정한다.
- (추측) 일시정지와 배속을 제공한다.

### ① 캐릭터 생성 (확정)

- 능력치 5종(안목, 인내심, 용기, 줏대, 운)과 초기 자산이 랜덤으로 정해진다.
- 운은 타고난 값이며 성장하지 않는다.

### ② 직업 선택 이벤트 (확정)

- 이벤트에서 선택지 몇 개가 제시되고, 그중 하나를 고른다.
- 직업의 목적은 **돈을 버는 것**이다. 직업이 투자 섹터를 정하지 않는다. (예: 농부라고 농업주가 나오지 않는다.)
- (추측) 직업마다 월급 수준과 안정성이 다르다. 정해진 선택지 풀은 PRD 확정 후 별도 스펙에서 정의한다.

### ③ 저축 단계 (확정 방향)

- 월급으로 자산을 모은다.
- 시간이 지나면서 **투자 성향을 형성하는 이벤트**가 발생한다. 이 이벤트의 결과로 관심 섹터가 정립된다.
- (추측) 능력치 성장 이벤트(투자 강의, 멘토와의 식사 등)도 이 단계에서 나오며, 월급을 쓰면 투자 자금이 줄어드는 고민이 생긴다.

### ④ 투자 시작 전환 (확정 방향)

- "투자를 시작해보겠다"는 시점에 핵심 루프가 시작된다.
- (추측) 어느 정도 시간이 지나면 이 전환 이벤트가 열리고, 사용자가 수락한다. 일정 시간 안에 수락하지 않아도 자동으로 열릴지는 미정.

### ⑤ 핵심 루프 (확정)

1. 뉴스 이벤트가 뜬다. 성향에 맞는 섹터 뉴스가 더 자주 나오고, 다른 섹터 뉴스도 일부 섞인다.
2. 안목에 따라 **애매한 힌트 문구**가 보인다. 확률 숫자는 보여 주지 않는다.
3. 사용자가 매수·매도·관망을 고른다.
4. 능력치 판정으로 선택이 뒤집힐 수 있다 (줏대 → 인내심/용기 순).
5. 결과 화면에서 "선택 → 실제 행동"과 원인, 손익을 보여 준다.

## 5. 능력치 (확정)

| 능력치 | 역할 | 부족할 때 | 성장 |
|---|---|---|---|
| 안목 | 정보 품질 | 힌트가 모호하거나 틀림 | 가능 |
| 인내심 | 과잉 행동 | 관망 선택이 충동 매수·패닉 매도로 바뀜 | 가능 |
| 용기 | 행동 불발 | 매수·매도를 눌러도 관망으로 바뀜 | 가능 |
| 줏대 | 외부 영향 | 다른 뉴스에 휘둘려 매수·매도가 정해짐 | 가능 |
| 운 | 결과 편차 | 손실이 더 크게 남 | 불가 |

- 후보: 탐욕(익절 못 하고 더 들고 감). 핵심 루프 확인 후 검토.
- 인내심 부족과 용기 부족은 **다른 문구와 연출**로 구분해 보여 준다.

## 6. 성공 기준

| 기준 | 측정 (추측) |
|---|---|
| 억울함이 동기가 됨 | 뒤집힘을 겪은 뒤 능력치 성장 이벤트를 선택하는 비율 |
| 원인이 이해됨 | 테스트 사용자가 결과 화면을 보고 원인을 설명할 수 있음 |
| 힌트가 의미 있음 | 안목이 낮을 때와 높을 때 사용자의 힌트 의존도가 다르게 나타남 |
| 반복 플레이 | 한 판 종료 후 다시 하기 선택 비율 |

## 7. 가정과 제약

- 플랫폼은 **반응형 웹 + PWA**다. PC와 모바일 브라우저에서 동작하고, 홈 화면에 추가해 앱처럼 실행할 수 있다. 앱스토어 앱은 현재 범위 밖이다. (확정)
- 모든 이벤트·종목은 가상이다. (추측)
- 한 판 길이는 10분으로 가정한다. (확정)
- 능력치는 설정 데이터로 정의해 추가·조정이 쉽도록 한다.
- 확률 수식과 계수는 체감 테스트 후 조정한다.
